# Fondos del juego

Los ocho fondos PNG ya están incorporados en esta carpeta y el juego utiliza sus nombres originales. Las rutas del código codifican los espacios y la tilde para que el navegador pueda cargarlas correctamente.

| Archivo | Uso dentro del juego |
|---|---|
| `FONDO 01 - Base Lunar Diurna.png` | Escena principal iluminada: días 0, 5, 25 y 30 |
| `FONDO 02 - Base Lunar Nocturna.png` | Escena principal nocturna: días 10, 15 y 20 |
| `FONDO 03 - Portada Principal.png` | Pantalla de inicio |
| `FONDO 04 - Tormento Solar.png` | Fondo de la alerta de tormenta solar, día 5 |
| `FONDO 05 - Impacto de Micrometeorito.png` | Fondo de la alerta de micrometeorito, día 15 |
| `FONDO 06 - Victoria.png` | Pantalla de victoria |
| `FONDO 07 - Derrota.png` | Pantalla de misión fallida |
| `FONDO 08 - Misión Incompleta.png` | Pantalla de misión incompleta |

**Nota:** se conserva el nombre original «Tormento Solar» del archivo para no romper la ruta; en el texto del juego el evento se llama «Tormenta solar». Las imágenes están en formato PNG. Si el juego tarda en cargar, se podrán optimizar más adelante sin cambiar su diseño ni su lógica.
