# Base Polar: Lunar Mission

An educational, turn-based lunar base management game built with HTML, CSS, and JavaScript for modern web browsers.

## How to run the game

1. Download or clone this repository.
2. Open the `base-polar-mision-lunar` folder in Visual Studio Code.
3. Open `index.html` in your browser. You can also use the **Live Server** extension to automatically reload changes.
4. Select **Start Mission**.

The game does not require Node.js, additional installations, or a server connection. External fonts are optional; fallback fonts are used when an internet connection is unavailable.

## Project structure

- `index.html`: screens, interface, and page structure.
- `styles.css`: responsive visual design for desktop and mobile.
- `game.js`: resources, actions, events, turns, and victory or defeat conditions.
- `audio.js`: music, sound effects, and alarms.
- `assets/`: the game's visual and audio assets.

## Main rules

- The mission lasts 30 days, divided into six five-day periods.
- Each period starts with 3 action points, which do not carry over.
- The scientific goal is to reach 100 points.
- The mission ends if oxygen, water, or energy reaches zero.
- Solar storms, lunar nights, micrometeorites, and extended darkness trigger events that require decisions.
- The encyclopedia provides scientific information and does not change the game state.

# Base Polar: Misión Lunar

Videojuego educativo de gestión lunar por turnos, desarrollado con HTML, CSS y JavaScript para ejecutarse en navegadores modernos.

## Ejecutar el juego

1. Descarga o clona este repositorio.
2. Abre la carpeta `base-polar-mision-lunar` en Visual Studio Code.
3. Abre `index.html` en el navegador. También puedes utilizar la extensión **Live Server** para recargar automáticamente los cambios.
4. Pulsa **Iniciar misión**.

No requiere Node.js, instalaciones adicionales ni conexión a un servidor. Las fuentes tipográficas externas son opcionales; el juego funciona con fuentes de respaldo si no hay conexión.

## Estructura del proyecto

- `index.html`: pantallas, interfaz y estructura.
- `styles.css`: diseño visual adaptable a escritorio y móvil.
- `game.js`: recursos, acciones, eventos, turnos y condiciones de victoria y derrota.
- `audio.js`: música, efectos de sonido y alarmas.
- `assets/`: recursos gráficos y audiovisuales del juego.

## Reglas principales

- La misión dura 30 días, distribuidos en seis periodos de cinco días.
- Cada periodo comienza con 3 puntos de acción que no se acumulan.
- La meta científica es de 100 puntos.
- Oxígeno, agua o energía en cero provocan el fin de la misión.
- Los eventos de tormenta solar, noche lunar, micrometeorito y oscuridad prolongada requieren decisiones.
- La enciclopedia presenta información científica y no modifica el estado de la partida.
